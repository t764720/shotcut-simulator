# محاكي برنامج شوت كت (Shotcut Simulator)

تطبيق ويب تفاعلي متكامل في **ملف HTML واحد فقط (Single-File)** يعمل بنسبة 100% بدون إنترنت (Offline) لمحاكاة واجهة ووظائف برنامج المونتاج الشهير **Shotcut** لأغراض التدريب والأنشطة العملية في معامل المدارس.

---

## 🚀 المميزات الرئيسية:
- **واجهة مستخدم مطابقة للسمة الداكنة لبرنامج Shotcut** باللغة العربية (RTL) مع المصطلحات الإنجليزية.
- **يعمل دون خوادم أو مكتبات خارجية (Zero Dependencies / Pure Vanilla JS):** متوافق مع كافة المتصفحات عند الفتح المباشر `file://`.
- **قائمة التشغيل (Playlist):** استيراد وسائط محلية (فيديو، صوت، صور) بالسحب والإفلات مع أزرار فورية لتوليد فيديو وصور تجريبية تعليمية جاهزة.
- **الخط الزمني (Timeline):** مسارات متعددة (`V2` للنصوص والمؤثرات، `V1` للفيديو الرئيسي، `A1` للصوت)، شطر المقاطع (`Split - S`)، تعديل البدايات والنهايات (Trimming)، وحذف المقاطع.
- **محرك المعاينة المباشر (Canvas Rendering Engine):** عرض الإطارات ومعالجة الفلاتر حياً.
- **حزمة فلاتر متنوعة:**
  - **نص بسيط (Text Simple):** مع إطار تحديد ومقابض تفاعلية لتكبير وتصغير حجم الخط ونقل الموضع بالسحب والإفلات المباشر على الشاشة.
  - **تأثيرات انتقالية حركية (Slide Transitions):** انزلاق من اليمين، اليسار، فوق، تحت، وتأثير المسح (Wipe) للداخل أو للخارج مع تحكم بالمدة.
  - **تدرج الألوان (Hue Rotate).**
  - **مرشح البني الداكن (Sepia Tone).**
  - **السطوع والتباين (Brightness & Contrast).**
  - **التدرج الرمادي (Grayscale).**
  - **التلاشي للداخل والخارج (Fade In/Out).**
- **تصدير ورندرة الفيديو الفعلي:** تسجيل الإطارات عبر `MediaRecorder` وحفظ ملف فيديو حقيقي جاهز للتشغيل.
- **وضع التدريب المعملي (Interactive Lab Mode):** قائمة مهام ذكية تتبع إنجاز الطالب خطوة بخطوة.

---

## 💻 طريقة التشغيل:
1. حمّل الملف `shotcut_simulator.html` من المستودع.
2. انقر نقراً مزدوجاً لفتحه في أي متصفح (Chrome, Edge, Firefox).
